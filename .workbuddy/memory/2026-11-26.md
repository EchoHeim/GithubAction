# 2026-11-26

## 新增：致美化（zhutix.com）每日签到

**结论先行**：致美化是 WordPress + B2 主题，签到**不需要浏览器**——cookie 里的
`b2_token` 就是 JWT，`main.js` 里写死 `Authorization: Bearer <b2_token>`，
纯 requests 几秒跑完。

### 接口（从 `Assets/fontend/task.js` 读出来的，不是猜的）

```
POST https://zhutix.com/wp-json/b2/v1/getTaskData     # 任务列表，签到项 finish/times
POST https://zhutix.com/wp-json/b2/v1/userMission     # 执行签到，无 body
POST https://zhutix.com/wp-json/b2/v1/getUserMission  # 连续天数 tk.days / 锋币 my_credit
```

- 无凭据统一回 `{"code":"task_error","message":"请先登录","data":{"status":403}}`
- 站点**不区分**「没给 token」和「token 过期」，都叫请先登录
- 不需要 WP nonce，不需要过验证码

### 关键判定（别改坏）

1. **成功判据只有一条：回查 `getTaskData` 里 finish 涨没涨。** 接口 200 不算数——
   `task.js` 自己是乐观派，`userMission` 一返回就把前端 finish 写死成 1，从不回读。
2. `/task/` 页长期挂着「签到和关注功能…暂时下线」的公告。脚本只在
   **签到被拒 + 公告仍在** 两个条件同时成立时判「站点已下线签到」并**退出码 0**。
   单看公告会把真失败洗成没事。
3. 403 登录态被拒不甩 traceback，只留一句能照着做的提示（CI 日志可读性）。
