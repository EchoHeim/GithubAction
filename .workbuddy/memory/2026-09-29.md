- 权限：`im:message` **或** `im:message:send_as_bot` 二选一；列群需 `im:chat:readonly`

- 卡片上限 30KB、文本 150KB；receive_id_type ∈ open_id/union_id/user_id/email/chat_id
- 换 token：`POST /open-apis/auth/v3/tenant_access_token/internal`
- 错误码：230025 超长 / 230027 缺权限 / 230034 receive_id 无效 / 230035 无发言权限 / 232009 群解散
