# 2026-11-24 学习强国（qiangguo）签到接入

## 结论先说

pc.xuexi.cn **只有扫码登录**（login.html bundle 里只有 qrcode，文案「用学习强国扫码登录」，
无密码/短信/第三方），但登录态就是一个 cookie `token`（domain `.xuexi.cn`，非 HttpOnly），
前端只判存在性，真正校验在后端 —— 所以复用 Cookie 等于登录，不需要扫码会话。

## 接口（真机实测，全部走 pc-proxy-api.xuexi.cn）

`pc-api.xuexi.cn` 是 `/open/api/auth/check`、`getGray` 用的，把积分路径拼上去一律 404。

| 用途 | 接口 | 字段 |
|---|---|---|
| 今日积分 | `GET /delegate/score/today/query` | `data.score`（5.0） |
| 今日进度 | `GET /delegate/score/days/listScoreProgress?sence=score&deviceType=2` | `data.totalScore`=**今日合计**；`taskProgress[]` 的各项 `title/currentScore/dayMaxScore`，筛 `periodType=1` |
| 累计积分 | `POST /delegate/score/detail/query` `{pageNo,pageSize}` | **没有总分接口**，取 `list[0].currentScore`（该笔入账后的累计值，倒序即当前总分） |
| 账号状态 | 同今日进度 | `inBlackList` / `needFaceRecognition` |

- `sence` 是站点自己的拼写错误，照抄。
- 假 token 打接口 → `401 {"message":"token check failed"}`，说明鉴权只认这一个值。

## 实现

- `Selenium/CheckIN/xuexi.py`：Cookie 登录 + 今日/累计积分 + 任务进度 + 飞书卡片。
  「登录」任务 1/1 就**不开浏览器**（今天的登录分已到账，省 30 秒）；
  未满且 `XUEXI_BROWSER=1` 才开积分页，开完**立刻回查**登录分有没有 0→1，不拿「页面打开了」冒充「登录分拿到了」。
- `XUEXI_BROWSER` 默认 **0**（跟别的站点相反）：本机 Selenium Manager 取 chromedriver 会被安全策略
  杀进程（SIGTERM，无日志，try/except 兜不住）；CI 里由 `setup-chromedriver` 提供，workflow 显式置 1。
- 接进 `check_in.yml`（`site=xuexi`）、`run_local.py`、`.env.local.example`、`LOCAL_RUN.md`、
  `.gitignore`（`xuexi-debug/`）。
- Secret 名 `XUEXI_COOKIE`，可直接贴 `token` 的值（脚本按名字判断而不是 `=`，避免 base64 补位误判）。

## 边界

脚本**不刷分**（不模拟阅读/观看/答题）。学习强国是行为积分，今日积分不涨是常态，
卡片上那个数字是对账用的。飞书 webhook 只在 GitHub Secrets 里，本机读不到，本地推送需自备。

## 补记：现行积分规则（2026-11-24 官方接口原文）

**`scoreDescription` 按 deviceType 返回两份不同清单**：PC（2）只有 4 项，
App（1）有 9 项 —— 差的 5 项（订阅2/观点1/本地频道1/趣味答题10/强国运动2）只在 App 侧。
所以脚本的 `read_progress` 固定传 `deviceType=1`，传 2 会把 14 分当不存在。

每日 8 项满分 **44**：登录1 + 选读文章12 + 视听学习12 + 每日答题5 + 趣味答题10
+ 订阅2 + 发表观点1 + 本地频道1。强国运动 `periodType=2`（**每周** 2 分），
所以缺口计算只算 `periodType=1`，否则一周里剩下六天会把它算成缺口。

- **活跃时段翻倍（2019 公告的 6:00-8:30/12:00-14:00/20:00-22:30）现行规则里已不存在**，
  网上教程全在抄老公告。2019 那套 12 项体系也早砍了。
- 阅读/视听各有两套独立计数：篇数（6）+ 时长（6），一篇文章同时喂两套 → 6 篇 ×1 分钟 = 12 分。
- 同篇/同个只算一次（时长除外）；时长只算正文页停留。
- 趣味答题三种题型每日轮换，只有当天那种能得分；挑战答题连对 3 题即 10 分，性价比最高。
