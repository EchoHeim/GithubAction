# 2026-09-23

## 富途种子脚本（ChromeSelenium/Futu/SeedFarm.py）新增「种子成熟」检测

背景：GitHub Actions 每 2 小时跑一次 `futu_seed.yml`。原 `farm()` 先等 `.opBtn.waterBtn .water_num`
拿今日剩余浇水次数，读不到就抛 `农场数据加载超时`。种子成熟时页面没有浇水入口，脚本会在这一步
整段中断，后面的好友互动（互动 tab → 筛选可施肥 → 施肥循环）永远执行不到。

改动：
- 新增 `FARM_PROBE_JS`：单次 `execute_script` 扫描返回 `{mature, evidence, hints, life, waterCount}`，
  成熟判定三信号（命中任一）：收获类控件可见（class 含 harvest/mature/shouhuo）/ 成熟关键词文案
  （已成熟、可收获、去收获…，刻意不含裸「成熟」以防「未成熟」误判）/ 气泡「生命剩下X天Y小时」归零。
  截图气泡锚点正则：`生命剩下\s*(\d+)\s*天\s*(\d+)\s*小时`。
- `inspect_seed()`：轮询 30s，遇成熟或读到浇水次数即返回，替代原 `WebDriverWait(ready_water_control)`。
- `notify_seed_matured()`：成熟时单独发一条飞书卡片（标题「富途种子｜成熟提醒」）+ dump `/tmp/futu_mature.png`；
  发送/截图失败只告警，不阻断主流程。
- `dismiss_overlay()`：成熟后常弹收获浮层挡住点击，先 ESC 再点浮层内 a/button/span 的关闭类文案
  （我知道了/确定/关闭…），只处理文案含成熟或关闭词的浮层，避免误点常驻 mask。
- 成熟时跳过自家浇水，直接进入好友列表；最终汇总卡片区分「已成熟未浇水 / 已浇水 / 次数用完」。
- `import json`（用于把选择器/关键词注入 JS）。

验证：`py_compile` 通过；用 mock DOM 在 node 下跑 5 条判定路径（生长期 / 收获控件 / 文案兜底 /
生命归零 / 次数为 0 不误判）全部 PASS。

注意：真实农场页 DOM 尚无快照（`futu-debug/futu_error.html` 是登录页），收获控件的实际 class 名
未经线上验证，依赖 `hints` 日志 + 失败时的 `/tmp/futu_mature.png` 反推选择器。
