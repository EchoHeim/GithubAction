### 新手法：不装 selenium 也能驱动 Chrome（很好用，记下来）

Node 22 自带 `fetch` + `WebSocket`，直连 CDP 就能做交互级复现（点击、读 DOM、抓 console）：

```
chrome.exe --headless=new --remote-debugging-port=9333 --user-data-dir=<临时目录> about:blank
PUT  http://127.0.0.1:9333/json/new?about:blank   -> webSocketDebuggerUrl
WS 发 Page.navigate / Runtime.evaluate（returnByValue + awaitPromise）
```

这次就是靠 `Runtime.evaluate` 点 `.login-btn` 后读 `.swal2-container`，才确认登录弹窗还活着、
进而把锅定到签到页 404 上。比 `--dump-dom` 强在能触发 JS 交互。
