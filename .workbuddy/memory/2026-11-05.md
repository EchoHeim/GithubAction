# 2026-11-05

## 富途种子 CI 失败排查（run #7195）

- 现象：`富途种子` 从 11-04 07:23 起连续 4 次失败，报错步骤是最后兜底的 `Fail if python failed`，真实错误在 annotation 里：
  `找不到输入框, 尝试过的 placeholder: [请输入密码...] (title=登录 url=...#/verifyPasskey)`
- 根因：富途按香港 SFC 要求推通行密钥（Passkey）。账号绑定过 passkey 后，提交账号会被直接带到 `#/verifyPasskey` 页，**没有密码输入框**。
- 从线上前端 `static.futunn.com/passport/script/home.2900f7da.js` 反查确认：
  - passkey 页两个按钮都是 `<input type="button">`：「立即验证」(`.submit-btn`)、「其他验证方式」(`.ghost-btn`)；
  - `useOtherMethods()` 直接 `$router.push({name:"verifyPwd"})`，即降级目标就是密码页，不需要中间再选一次。
- 修复（`Selenium/Futu/SeedFarm.py`）：
  1. `click_text_js()` 取文本时对 INPUT/TEXTAREA 读 `value`（原先只读 innerText，点不到整类按钮）；
  2. `click_submit()` 增加 `//input[@type='button']` 匹配；
  3. 新增登录阶段探测 `probe_login_stage/wait_login_stage`，命中 passkey 页自动点「其他验证方式」降级；
  4. 失败时把页面可见文案/输入框属性（`describe_page`）写进异常消息 —— GitHub annotation 手机端可读，下次失败能直接改选择器。
- 待验证：需 push 后 dispatch 一次。风险：若该账号从未设置过密码，verifyPwd 会提示未设置密码；短信验证码路径 CI 无解。
- 长期隐患：每 2 小时换 runner IP，风控会持续触发设备验证，建议后续评估登录态（cookie/profile）持久化方案。
